# 使用用户

解决问题：在当前身份的权限范围内查找、读取和处理文件。

## 操作流程

1. 登录组织提供的 CloudFile 实例，确认目标资料库和目录；不能仅凭显示名推断唯一目标。
2. 通过目录浏览定位文件；只有实例已启用且当前用户可用时才使用搜索。
3. 下载或预览需要的文件；上传、替换或编辑时确认目标路径与覆盖范围。
4. 操作后重新读取文件或版本信息，确认结果。超时后先查原结果，避免重复写入。

正常结果：当前身份能访问目标文件，读取或修改结果可核实。遇到拒绝访问时记录脱敏的时间、动作和错误，交给管理员核对身份及有效权限，不切换到管理员身份绕过限制。

通用界面操作参考 [Seafile 用户手册](https://cloud.seafile.com/wiki/publish/seafile-user-manual/)，以当前 CloudFile 版本为准。

AI 协助见 [cloudfile-files](../../skills/cloudfile-files/SKILL.md)；工具状态见 [CLI 规划](../cli.md)。
