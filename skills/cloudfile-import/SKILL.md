# CloudFile Import

读取 [实施手册](../../docs/implementation/README.md) 和 [Agent 边界](../../docs/ai.md)。保留完整 Toolkit 目录以解析引用。

需要多轮增补、时间保留、错误隔离或大库优化时，读取 [多轮迁移设计](../../docs/implementation/migration-design.md)；选执行器前读取 [工具索引](../../docs/implementation/tools.md)，不能把不同工具的校验和恢复语义混用。

先确认源、目标 UUID 与路径、策略和授权，再形成可审阅计划。复用实际可用执行器及其帮助；Toolkit CLI 尚未实现，不能把规划命令当现成工具。原工具不兼容目标存储时停止依赖该路径并说明缺口，不临时绕过存储契约。

保留源相对路径和枚举取得的时间等版本依据。优先经验证的同目录合批与持久状态；Agent 执行任务级动作，文件队列与恢复由执行器管理，不逐文件调用 AI。

增量比较上次成功导入的源版本，按只新增、更新变化或定向修错限定范围。目标时间错误不能独自触发内容重传；未验证的时间保留标记待修。默认只读增量元数据核对，证据不足保留 unknown，不自动升级为内容哈希；正常增补不要求先全库核对。

超时先查原任务及目标结果，只恢复未确认或变化项。报告成功、失败、跳过、待确认及错误例外，区分上传完成与迁移验收；停写、最终差量、完整性、索引、权限和业务验收完成前不发布目标库。
