# CloudFile Diagnose

按问题读取 [支持手册](../../docs/support/README.md) 或 [运维手册](../../docs/operations/README.md)，并遵守 [Agent 边界](../../docs/ai.md)。引用要求完整 Toolkit 目录。

确定环境、实际运行版本、当前身份、故障时间和失败动作。通过实际存在的只读工具检查连接、认证、授权或传输阶段；规划中的 doctor/status/access explain 尚未实现，不能猜测执行。

限制日志窗口、样本数和查询范围，优先已有汇总。权限解释只能来自服务端真实机制；能力不可用时说明缺口，不根据客户端规则推算授权结论。

将已证实事实、推断与待验证项区分开，给出下一项能验证的动作。查询失败或身份不足时停止该诊断路径，不自动提升权限。修复、服务变更与维护需回到对应授权及维护入口。

报告环境、证据、影响范围、未解决项与建议；脱敏凭据和个人信息，不能将测试或源码提交视为生产验收。
